## Description

This project builds on the original example by adding a custom debug system to the game. A debug menu can be opened using the F key, allowing players to toggle features like moon gravity and fast movement. When debug mode is active, the screen darkens, a wolf meme appears, and a different music track plays to create a more immersive “debug - alpha mode” experience. All features were added on top of the existing code without restructuring the original system.

---

## Learning Goals

Learning Goals:

- Learn how to add a debug system to an existing game
- Practice using key inputs to toggle game features
- Adjust gameplay values like gravity and speed
- Learn how to display UI elements and overlays on screen
- Implement sound and images to enhance user experience
