## Description

This project builds on the original blob game by addinng new in-game levels and game elements into the sketch and JSON file. The game includes two levels, a start screen, an end screen, and a simple goal where the player collects a money emoji to advance.

---

## Learning Goals

Learning Goals:

- Learn how to add another level to an existing game file
- Learn how to implement a start and end screen
- Load external JSON data in preload()
- Recall how to add and adjust image files
- Update and draw game elements each frame
